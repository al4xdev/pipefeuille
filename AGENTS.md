# Instructions for agents in this repository

This is the pipefeuille: the guide and the template for agent projects built as vertical pipelines.

Before any action, read [`RUNBOOK.md`](RUNBOOK.md). It tells you what your task is here (start a new project, work on a project born from the template, or maintain the pipefeuille) and the step-by-step for each one.

`template/AGENTS.md` applies to work inside `template/` and to every project copied from it.
